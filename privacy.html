이 기기에 저장하는 정보

영상 링크·제목·채널명·재생목록 순서·현재 선택한 곡·전환 설정·음량·반복 설정·처음 재생한 고유 영상 최대 14개의 ID를 브라우저 또는 앱의 로컬 저장공간에 보관합니다. 재생목록 복원과 튜토리얼 진행 표시를 위한 정보입니다. YouTube 연결 동의 여부도 기기에 저장합니다. 클라우드 재생목록 서버는 현재 없습니다.

설치형 앱에서 세트를 내보내면 앱 전용 캐시에 임시 JSON 파일 하나를 만듭니다. 새 내보내기는 같은 파일을 갱신합니다. 아래 삭제 버튼은 이 임시 파일도 삭제합니다. 공유받은 다른 앱의 복사본은 해당 앱에서 관리해 주세요.

기기의 음악 파일을 선택할 때

파일 음원 모드에서 선택한 음악 파일은 서버에 업로드하지 않습니다. 파일 정보를 읽고 PCM 파형·추정 BPM·박자를 이 기기에서 분석하며, 현재 곡과 다음 곡의 재생용 오디오 버퍼를 사용합니다. 선택한 파일·파일 목록·분석 결과는 영구 저장하지 않으므로 새로고침하거나 앱을 다시 열면 파일을 다시 선택해야 합니다. YouTube 음원을 추출하거나 처리하지 않습니다.

YouTube에 연결할 때

동의하고 연결하면 YouTube 공식 플레이어가 로드됩니다. 영상 재생과 영상 정보 확인, 곡 썸네일(i.ytimg.com) 표시를 위해 Google/YouTube에 연결하며, IP 주소·기기 및 브라우저 정보·영상 요청과 쿠키 등의 처리는 Google 정책에 따릅니다. 웹 개발 서버에서는 영상 ID를 고정 YouTube oEmbed 주소에 전달해 제목과 채널명을 가져옵니다. 동의 전에는 SCYL이 YouTube 플레이어·영상 정보·썸네일 요청을 시작하지 않습니다.

Google 개인정보처리방침 · YouTube 이용약관

MEOW · SCYL 공통 계정

공통 계정이 연결된 배포 버전은 MEOW와 같은 Supabase Auth에서 이메일 가입·로그인을 처리합니다. 이메일·비밀번호 로그인과 이메일 본인 인증을 지원합니다. 비밀번호는 공통 인증 서비스로 안전하게 전송하며 SCYL의 프로필·기기 저장공간에는 저장하지 않습니다. 이메일 주소와 인증된 회원 ID를 사용하고 로그인 유지용 세션을 이 기기에 저장합니다. 다음 로그인 때 이메일을 다시 입력하지 않도록, 로그인에 성공한 이메일 주소를 이 기기에 기억합니다. 로그아웃해도 이메일은 남으며 아래 데이터 삭제 버튼으로 지울 수 있습니다. 인증 메일은 Supabase 인증 서비스와 설정된 메일 제공자를 통해 발송됩니다. 음악 파일·분석 결과·재생목록은 인증 서버로 전송하지 않습니다. SCYL 로그아웃은 이 기기의 SCYL 세션만 종료하며 MEOW 계정은 삭제하지 않습니다. 웹 주소를 열 때 ChatGPT 로그인을 요구하지 않습니다. 음악 이용을 위한 공통 회원 인증은 유지합니다.

고양이와 MBTI 선택

이메일과 회원 ID는 두 앱의 공통 인증 계정에서 관리합니다. 고양이 종류와 MBTI는 공통 회원 프로필 한곳에 저장하며 MEOW와 SCYL이 같은 정보를 불러옵니다. 기존 MEOW에서 서버에 확정한 선택이 있으면 그 정보를 사용합니다. 이 선택만으로 MEOW의 동네 공개·위치 공유가 켜지지는 않습니다. 아래 기기 데이터 삭제 버튼은 서버의 계정·프로필을 삭제하지 않습니다.

광고와 결제

SCYL 자체 광고 SDK, 유료 결제, 가족 계정은 현재 연결되어 있지 않습니다. YouTube 영상에는 Google이 제공하는 광고가 표시될 수 있습니다. 추후 SCYL의 광고·구독 기능을 도입할 때 수집 정보와 처리 목적을 업데이트하고 필요한 동의를 받습니다.

개발 시제품 안내

이 안내는 현재 시제품의 실제 데이터 흐름을 설명합니다. 운영 주체·개인정보 문의 연락처·공개 방침 주소는 스토어 배포 전에 확정하여 고지할 예정입니다. 현재 정식 스토어 배포용 방침으로 확정된 상태는 아닙니다.
