# SCYL 톤앤매너 · 고정 매핑

사용자 재확인: 2026-11-26. 처음 제시한 레퍼런스의 **회색 바탕·짙은 회색 글자·주황 포인트와 통일된 폰트**를 모든 화면과 새 요소에 계속 적용한다. 새 기능을 만들 때 별도의 색상이나 폰트를 임의로 도입하지 않는다.

실제 구현 기준은 `theme.css` 한곳에서 관리한다. 로그인, 이메일 인증, 비밀번호, 고양이·MBTI 선택, 계정 배지, 두 플레이어, 개인정보 화면이 같은 토큰을 사용한다.

| 역할 | 토큰 | 값 |
| --- | --- | --- |
| 공통 폰트 | `--font-ui` | Arial, Helvetica Neue, Apple SD Gothic Neo, Malgun Gothic, sans-serif |
| 바깥 회색 바탕 | `--canvas` | `#DEDED9` |
| 본 화면 바탕 | `--paper` | `#F4F3EE` |
| 입력·카드 표면 | `--surface` | `#F8F7F3` |
| 본문·조작부 | `--ink` | `#30312D` |
| 보조 글자·다음 곡 | `--muted` | `#797A72` |
| 테두리·구분선 | `--line` | `#D7D6CF` |
| 선택·포커스·현재 곡 | `--accent` | `#E75C2B` |

주요 규칙:

- 새 화면에서 `system-ui`, `Segoe UI`, `-apple-system` 같은 별도 폰트 묶음으로 바꾸지 않는다. 폼과 버튼도 공통 폰트를 상속한다.
- 제목은 원래 플레이어의 보통 굵기(500)를 유지한다. 기본 브라우저 굵은 제목이 계정 화면에 따로 생기지 않게 한다.
- 주황은 선택선·작은 표시·포커스에 사용한다. 고양이 선택 배경을 복숭아색이나 다른 강조색으로 만들지 않는다.
- 현재 곡은 주황, 다음 곡은 회색이다. 범례와 실제 캔버스 파형이 같은 색상 토큰을 읽는다.
- 고양이는 MEOW 투명 원본을 그대로 쓴다. 로고·고양이·국기·앨범 이미지를 회색으로 재색칠하거나 새로 생성하지 않는다.
- 계정 배지에는 고양이 아래 작은 MBTI를 둔다. 공통 폰트를 유지한다.
- 파일 믹싱 화면의 범례와 사용 설명은 첫 번째 원 위에 둔다. 두 원 사이에는 전환 제목·상태와 실제 전환 그래프만 둔다.

근거: 최초 공개 소스 `db78a7c`의 `style.css`, 초기 파일 믹싱 `751a354`, 공통 정체 폰트로 FX를 통일한 `b74a9ef`, 기존 `docs/product-direction.md`. 최초 사용자 레퍼런스 이미지 파일 자체는 이번 점검에서 다시 특정하지 못했으므로 새 폰트를 추정하지 않고 기존 구현의 폰트·주색을 보존했다.

스타일 변경 후에는 실제 배포물의 공통 CSS 포함 여부와 모바일 폭에서의 레이아웃을 확인한다. 매핑 문서만 바꾸고 화면까지 수정했다고 보고하지 않는다.
