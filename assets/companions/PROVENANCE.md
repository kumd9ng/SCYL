# MEOW 고양이 원본 자산

이 폴더의 네 PNG는 사용자의 기존 MEOW 프로젝트에서 사용하는 선택기 얼굴 원본을 변경 없이 복사한 것입니다. 새 캐릭터를 만들거나 그림을 다시 편집하지 않았습니다.

- 생성일: 2026-11-10
- 기존 제작 기록: MEOW의 docs/meow-cat-assets.md
- 제작 방식: 내장 이미지 생성 도구로 제작하고 같은 도구로 평면 선화 스타일로 정리한 사용자 프로젝트용 이미지
- 원본 기록에 따르면 사람 사진·수집한 품종 사진은 사용하지 않았습니다.
- 4개 원본 atlas: portraits-core.png(4열·3행, 12개), portraits-a.png/portraits-b.png/portraits-c.png(각 6열·6행, 36개)
- 얼굴 그룹 120개, 같은 그림을 쓰는 변형을 포함한 목록 ID 144개
- 품종·형태에 영감을 받은 일러스트이며 품종 판별용 자료가 아닙니다.
